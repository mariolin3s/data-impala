# GA4 Alert Monitor

Dashboard de monitorización de alertas para eventos de Google Analytics 4.

## Descripción

Esta aplicación permite visualizar y gestionar alertas basadas en el tráfico y eventos de GA4, proporcionando una interfaz moderna para la toma de decisiones basada en datos.

## Tecnologías

- **Vite** para el entorno de desarrollo y construcción.
- **React** para la interfaz de usuario.
- **TypeScript** para el tipado estático.
- **Tailwind CSS** y **shadcn/ui** para el diseño y componentes.
- **Recharts** para las visualizaciones de datos.

## Desarrollo Local

1. Instalar dependencias:
   ```bash
   npm install
   ```

2. Ejecutar en modo desarrollo:
   ```bash
   npm run dev
   ```

3. Construir para producción:
   ```bash
   npm run build
   ```

## Características

- Visualización de historial de estados por alerta.
- Gráficas de tendencias de eventos.
- Filtrado dinámico por rango de fechas.
- Interfaz responsive y optimizada.
